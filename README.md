# www.unboundworksllc.com

Static site for Unbound Works LLC. Plain HTML and CSS, no build step.

- `index.html`, `what-we-build.html`, `approach.html`: pages
- `styles.css`: all styling (design tokens in `:root`)
- `404.html`, `favicon.svg`, `og.png`, `robots.txt`, `sitemap.xml`: site plumbing

Preview locally: double-click `test-site.bat` (Windows, needs Python), or run `python -m http.server 8000` and open http://localhost:8000.
